# Tool logo assets

These local, unmodified SVG marks are used only as small identifiers in the existing Systems & Work tool chips.

- GitHub, Airtable, Google Cloud, Zapier, Gmail, and Google Drive: [Simple Icons](https://github.com/simple-icons/simple-icons), pinned to release `16.35.0`; CC0-1.0.
- Jotform: official dark icon from [Jotform Brand Assets](https://www.jotform.com/resources/), downloaded from its SVG asset. Jotform requests that its logo not be distorted, recolored, or reconfigured; the SVG is preserved and proportionally contained.

The tool names remain visible text. Real Geeks is shown as a text-only chip because no verified suitable logo asset was found.
