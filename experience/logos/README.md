# Tool logo assets

These SVGs are small identifiers in the Systems & Work ticker. The ticker applies its existing CSS mask so the marks use the same monochrome foreground color as their labels.

- Airtable, GitHub, Google Cloud, Zapier, Gmail, Google Drive, Supabase, Cursor, Python, and Fly.io: [Simple Icons](https://github.com/simple-icons/simple-icons), pinned to release `16.35.0`; CC0-1.0.
- Codex: monochrome icon from [Devicons](https://devicons.io/icons/codex/) v1.2.0; its icon metadata links to [OpenAI Codex](https://openai.com/codex/). Devicons does not publish a license for this brand asset.
- OpenAI: `OpenAI-black-monoblossom.svg` from the [official OpenAI 2025 logo package](https://cdn.openai.com/brand/OpenAI-Logos-2025.zip), used as the supplied monochrome mark.
- API / MCP: generic connector/network geometry created for this ticker. It represents a protocol category, not a company or product brand.
- Google Workspace remains paired with the existing Google Drive mark. Google's official Workspace package provides a wordmark and image-format marks, but no suitable standalone SVG was available for this CSS mask. This remains a known label-to-mark mismatch.
- Encompass: monochrome ring motif adapted from the approved Database 2.0 illustration for consistent ticker rendering.

- Jotform: official dark icon from [Jotform Brand Assets](https://www.jotform.com/resources/), downloaded from its SVG asset. Jotform requests that its logo not be distorted, recolored, or reconfigured; the SVG is preserved and proportionally contained.

All ticker entries retain visible text labels. Real Geeks is also text-only because no verified suitable logo asset was found.
